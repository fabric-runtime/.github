# Fabric Runtime profile

`profile/README.md` is the public GitHub organization profile.

The approved avatar and text-free particle banner are maintained in [pi-fabric/media/opencollective/fabric-runtime](https://github.com/fabric-runtime/pi-fabric/tree/main/media/opencollective/fabric-runtime). The profile links directly to those canonical assets. Keep the fa. lettering crisp and separate from the cover; preserve near-black `#151515`, warm white `#F4F3EF`, and cobalt `#356AF0`. Do not add gradients, glows, or replacement artwork.

Project names, package scopes, executable names, and funding scope are intentional. There is no organization-wide FUNDING file: the Pi Fabric collective funds Pi Fabric only.

Check all project descriptions and install links against their current READMEs before changing this profile. Preview `profile/README.md` on GitHub and verify its image URLs after every update.
